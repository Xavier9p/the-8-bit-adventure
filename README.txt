!!!README!!!


Installation
  * Ensure you have Python 3.11.0rc2 or better installed.
  * Install the required library: pip install (2.22.2 version) & pgzero
  * Run the game with: pgzrun GAME.py


Game Objective
    * Complete all 5 levels.


Moves  
  * WASD to move the character;
  * Enter or left mouse buttons to shoot;
  * Space to jump.


Features
  * High Score system saved in a local file (JSON).
  * Platform and Ladder mechanics with gravity physics.
  * Enemies with Automatic Patrol and random shooting.
  * Lives and temporary immunity system.
